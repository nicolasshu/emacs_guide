** Saving and Quitting

- =:w=: Save the current file
- =:w filename=: Save as a new file named "filename"
- =:q=: Quit the file (it fails if there are unsaved changes)
- =:q!=: Force quit and discard all changes
- =:wq= or =:x=: Save and quit the file
- =:wa=: Save all currently open files

* Commands

** Search and Replace

- =:s/old/new/=: Replace the first occurrence of "old" with "new"
- =:s/old/new/g=: Replace ALL occurences of "old" with "new" in the current line
- =:%s/old/new/g=": Replace globally across the entire file
- =:%s/old/new/gc=: Replace globally with a prompt asking for confirmation before each change

** File and Buffer Management

- =:e filename=: Open and edit a specific file
- =:r filename=: Insert content of an external file directly below the cursor
- =:ls=: List all open buffers
- =:b <number>=: Switch to a buffer by its listed number
- =:bd=: Delete the buffer
